# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in libthai-idcard, please report it by emailing the maintainer at [me@phakhawat.com](mailto:me@phakhawat.com).

Please do **not** file a public GitHub issue for security vulnerabilities.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |
